# 人工智能数字人训练师赛项 · 考试大纲与考点清单

> 依据：①赛项通知原件 ②官方样题（中国信息协会 2026-09-02 公布，含参考答案）③《人工智能训练师国家职业技能标准（2021 年版）》原文

## 一、赛事概况

| 项目 | 内容 |
|---|---|
| 赛事全称 | 2026 年全国行业职业技能竞赛暨首届全国信息技术服务业职业技能竞赛 · 人工智能数字人训练师赛项（国家二类赛） |
| 主办 | 中国信息协会、中国就业培训技术指导中心 |
| 承办 | 中国职工技术协会网络安全专业委员会、中电运行（北京）信息技术有限公司 |
| 组别 | 职工组 / 学生组，均为**单人赛** |
| 成绩构成 | **理论考试 30% + 实操 70%** |
| 命题依据 | 《人工智能训练师国家职业技能标准（2021 年版）》**三级/高级工及以上**（高级别涵盖低级别要求） |
| 省级选拔赛 | 2026 年 9 月，全国统一命题、统一评分标准，按成绩排序晋级 |
| 全国总决赛 | 2026 年 10 月，北京，"理论知识 + 实操技能"方式 |
| 报名 | 2026-09-08 12:00 至 2026-09-30 18:00，官网 https://cmdr.com.cn（免费） |
| 奖励 | 决赛前 3 名晋升技师（已有技师升高级技师）；4–15 名晋升高级工/技师；一/二/三等奖比例 10%/15%/25% |

**工种背景**：人工智能数字人训练师是人社部 2024 年 7 月在"人工智能训练师"职业（4-04-05-05）下增设的新工种，核心工作：筛选结构化数据、设计提示词（Prompt）框架、构建垂直领域知识库、为数字人配置表情/动作/场景的多模态交互。

## 二、考试形式分析（基于官方样题）

官方样题为一套合卷模拟试卷：**总分 100 分、考试时间 90 分钟**，"对标竞赛正式命题考核框架、题型结构和难度层级，适用于省级选拔赛及决赛备赛参考"。

| 部分 | 题型 | 题量 | 分值 | 形式 |
|---|---|---|---|---|
| 一 | 单选题 | 45 题 × 1 分 | 45 分 | 机考/笔试 |
| 二 | 实操题 | 4 大题（5 个任务模块） | 55 分 | 考试系统上机操作 + 主观方案设计 |

实操 55 分的任务结构：
1. 数据业务分析（SQL + 维度/指标 + 过滤条件）— 15 分
2. Python 数据处理 + 逻辑回归算法测试 — 16 分
3.（1）智能系统监控与优化（BI 热力图）— 9 分；（2）人机交互工程设计（流程图）— 12 分
4. 数字人主播训练方案设计（主观题）— 3 分

> 注：通知口径为"理论 30% / 实操 70%"，样题卷面为 45/55，两者不完全一致——决赛可能分场分卷。按样题结构准备最稳妥；同类竞赛理论部分还出现过**多选题、判断题**，建议一并练习。

## 三、理论考点清单

### 模块 A：职业道德与基础知识（标准权重约 15%）
- [ ] 职业守则三条款：诚实公正、严谨求是；遵章守法、恪尽职守；勤勉好学、追求卓越
- [ ] 计算机操作、常用办公软件
- [ ] 相关法律法规：劳动法、劳动合同法、**网络安全法**、知识产权法
- [ ] 数据安全与个人隐私保护（数字人处理用户数据的**首要**考虑：数据安全性与隐私保护）

### 模块 B：数字人领域专业知识（工种特色，样题约占 1/3 题量）
**B1 基本概念**
- [ ] 数字人训练师的聚焦层面：**外观、音色、行为设计与多模态交互**（不涉及底层算力/网络协议）
- [ ] "会展示"→"能服务"的核心驱动力：构建**垂直领域知识库**并降低**幻觉率**
- [ ] 实用价值关键能力：理解上下文逻辑、预判用户需求（金牌导购式）

**B2 训练体系**
- [ ] 构建"人格特征与交互逻辑"的首要工作：设计 **Prompt 提示词框架**并定义人设
- [ ] 降低幻觉率最关键举措：接入精准的垂直领域业务知识库（如金融场景）
- [ ] 训练师团队多元化的原因：需理解"人、行业与表达"，具备感性与共情能力

**B3 关键技术**
- [ ] 实时口型同步依赖：**视觉捕捉与面部动作映射**；TTS/NLP/ASR 的概念区分
- [ ] 超拟人数字人实时生成技术：仅需**一张照片**即可实时生成可交互数字人
- [ ] 情感标签维度（VAD 模型）：**愉悦度、激活度、支配度**
- [ ] 体感设备：手势/动作交互

**B4 应用场景**
- [ ] AI 数字人短视频制作流程：脚本编写 → 角色设计 → 后期剪辑（**不含实地拍摄**）；优势：成本低、周期短、人力少
- [ ] 产品展示说服力设计：**声音、表情、动作与文本的高度统一联动**
- [ ] AI 主播本地化适配：方言词汇库、本地新闻库、民俗文化表情库（不是通用翻译模型）
- [ ] 文本类业务数据预处理（语义分析场景）：标注分词、句法判别

### 模块 C：业务分析（理论 20% / 技能 25%）
- [ ] 梳理业务流程的目的：制定业务数据的**采集、处理、审核**流程
- [ ] 处理单个业务数据需兼顾：**业务流程 + 数据特征**
- [ ] 业务构建流程的目的（描述系统功能）、业务流程优化的目标（提高效率）
- [ ] 流程分析：理解**步骤、活动和决策点**之间的关系
- [ ] 智能系统改造法、复杂综合业务流程优化目标
- [ ] **特征工程**：将文本转化为更容易结构化的数值数据特征
- [ ] 个性化推荐（电影/音乐）：**协同过滤**
- [ ] 最优化决策：利用 AI **最大化业务指标**
- [ ] 远程智能诊疗：通过**电子病历**进行诊断治疗
- [ ] 视觉类数据以**点阵图像**方式存储；图像描述使用**文本描述**

### 模块 D：智能训练（理论 30% / 技能 35%）
**D1 数据处理规范制定**
- [ ] 数据清洗的目的：取得**高质量数据** / 提高数据可用性
- [ ] 文本类清洗、视觉类清洗规范（依据**业务需求**制定；去除损坏图像/视频的原因）
- [ ] 标注类型辨析：**实体标注**（商品名、数量、价格、日期属之）、关系标注、属性标注、情感标注、词性标注、文本类别标注
- [ ] 中文分词质量标准（与词典一致、无歧义）
- [ ] 设计数据清洗和标注流程、制定清洗标注规范（三级技能要求）

**D2 算法测试**
- [ ] 训练集/测试集划分（8:2、random_state）
- [ ] 逻辑回归等分类模型训练（sklearn）
- [ ] 分类算法评价指标：**准确率、精确率、召回率**（运行时间不属于）
- [ ] Keras：`evaluate` 默认返回 **[损失值, 准确率]**；`compile` 中 **`loss`** 参数指定损失函数（`metrics` 指定评估指标、`optimizer` 指定优化器）
- [ ] AI 在线开发平台：百度飞桨 EasyDL、华为云、阿里云（ChatGPT 手机 App 不属于）
- [ ] 错误案例原因分析与纠正、测试报告编写（标准技能要求 2.2.4/2.2.5）

### 模块 E：智能系统设计（理论 30% / 技能 35%）
**E1 智能系统监控与优化**
- [ ] 数据可视化：热力图等图表类型选择、行维/列维/指标列与聚合函数、过滤条件
- [ ] 由数据分析 → 输出分析报告 → 提出优化需求 → 设计智能解决方案（标准 3.1 技能链）

**E2 人机交互流程设计**
- [ ] 视觉交互方式：手势识别、表情识别、姿态识别（**情感识别**不属于视觉交互方式）
- [ ] 通过数据分析找到单一场景下人工与智能交互的最优方式/最优流程
- [ ] 流程图设计：判断节点、分支逻辑（登录方式采集案例）

**E3 智能产品开发**
- [ ] AI 开发特有的极重要环节：**数据准备**
- [ ] 硬件呈现的智能产品：**工业设计、结构设计、硬件设计**

### 模块 F：培训与指导（5%）
- [ ] 编写初级培训讲义、对五级/四级人员开展培训与指导（职工组、对标技师层级时留意）

## 四、实操考点清单（5 个任务模块，55 分）

### 任务 1：数据业务分析（15 分）— 数据分析考试平台
| 考点 | 要求 |
|---|---|
| SQL 创建数据集 | 数据集命名；`select 字段 as 别名`；`from 表名 别名`；`where 字段 in (...)` 范围过滤 |
| 维度列/指标列 | 新增分组；设置维度列并编辑别名；设置指标列 |
| 过滤条件 | 命名；组合条件（如年龄 18–22 且访问次数 ≥50） |

**易错点**：数据集/过滤条件的命名必须与题目完全一致；字段与别名一一对应；SQL 关键字与引号内中文值格式。

### 任务 2：Python 数据处理 + 算法测试（16 分）
```python
import pandas as pd
data = pd.read_csv('/studymnt/01/data.csv')
data.head(15)          # 前 15 行
data.describe()        # 描述性统计
data.dropna()          # 缺失值（重复值：data.drop_duplicates()）

from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
X = data['预估薪资']; y = data['是否会购买']
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=2020)
X_train = X_train.values.reshape(-1,1)   # 一维特征转二维数组
X_test  = X_test.values.reshape(-1,1)
model = LogisticRegression(); model.fit(X_train, y_train)
accuracy = model.score(X_test, y_test)   # 准确度
y_pred = model.predict(X_test)           # 预测值
```
**易错点**：`reshape(-1,1)` 忘写；`test_size=0.2` 对应 8:2；按题目要求"输出"必须 print。

### 任务 3：智能系统监控与优化（9 分）
- 选择数据集 → 图表类型（样题为**热力图**）→ 标题设置 → 行维/列维/指标列（含**聚合函数 sum**）→ 过滤条件（数值区间 + 类型枚举）
- 基于图表的统计分析判断（如新用户推送哪类资讯 → 看热力值最高的类型）

### 任务 4：人机交互工程设计（12 分）
- 补全流程图判定条件（样题：掌上钱包用户信息采集——设置登录信息 → 账号密码 / 人脸采集 / 指纹采集 / 手机号验证的分支顺序）
- 考核点：分支完整性、条件命名与题目一致、最优流程逻辑

### 任务 5：数字人训练方案设计（3 分，主观题）
按三段式作答（可背模板）：
1. **人格设定**：≥3 个人设关键词（温柔、专业、亲和力）+ 对应语言风格要求（语气柔和、讲解清晰、肯定性鼓励语言、情感连接）
2. **交互设计要点**：实时应答、主动引导、情绪适配 + 训练重点（自然语言理解准确性、回应时机把握）
3. **多模态联动**：语音（细腻描述）+ 表情（专注/惊喜等正面情绪）+ 动作（模拟涂抹、展示包装）协同

## 五、备考行动建议

1. **立即报名**：cmdr.com.cn（9 月 30 日 18:00 截止）；省选拔赛拟定 9 月举行，时间紧迫。
2. **吃透样题**：样题即命题框架，单选 45 题逐题归类到本大纲模块，错题回标准原文对应条款。
3. **实操每日一练**：
   - SQL：select/as/from/where in 手写
   - pandas + sklearn：读数→清洗→划分→训练→评估→预测 全流程默写
   - BI 图表：找任一自助 BI 平台（如帆软 FineBI / 百度 Sugar）练热力图、柱状图的维度指标配置
   - 流程图：Visio/在线工具画多分支判断流程
4. **数字人领域补强**：了解主流数字人平台（讯飞智作、腾讯智影、华为云 MetaStudio、硅基智能）的基本制作流程（形象→音色→播报→交互）；跟踪行业动态新闻（样题考了讯飞"一张照片生成数字人"）。
5. **理论刷题**：人工智能训练师三级/高级工理论题库（单选+多选+判断），重点职业道德、数据处理、算法测试、人机交互。
